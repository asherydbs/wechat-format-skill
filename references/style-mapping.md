# 文章风格→排版风格映射指南

判断一篇文章该用哪种排版风格时，看这三个维度：

## 决定性信号

### → 温墨 (ink)
```yaml
触发词: ["记得", "小时候", "有一次", "那时候", "感觉", "后来", "也许", "回忆"]
结构: 段落为主，代码块=0，列表罕见
人称: 第一人称密集（"我"、"我们"）
语气: 叙述、回忆、感受
场景: 散文、随笔、小说、叙事
```
**关键判据：** 以叙述个人经历或感受为主线，不以说理/教学为目的。

### → 青蓝 (azure)
```yaml
触发词: ["教程", "步骤", "安装", "配置", "实现", "方法", "函数", "代码"]
结构: 有代码块、列表、表格
人称: 第二人称或无人称（"你"或中性）
语气: 指导、讲解、说明
场景: 技术教程、操作指南、方法论、工具介绍
```
**关键判据：** 有代码块或结构化步骤说明。教程类即使含个人口吻也归此类——传播力最高。

### → 赤丹 (cinnabar)
```yaml
触发词: ["为什么", "我建议", "反对", "警惕", "反思", "批判", "别再"]
结构: 引用块多、短段落
人称: 第一人称（"我"但用于表态而非叙述）
语气: 判断、主张、评价、反问
场景: 观点文、评论、檄文、深度分析
```
**关键判据：** 文章目的是说观点、下判断、引发讨论，不是教人做事或讲故事。

## 边界案例

| 实际情况 | 适用风格 | 理由 |
|----------|---------|------|
| 教程但开头有个人经历 | 青蓝 (azure) | 核心是教学，开头是引子 |
| 叙事中有大量说理 | 赤丹 (cinnabar) | 目的是表达观点而非讲述经历 |
| 纯抒情无事件无观点 | 温墨 (ink) | 散文本质 |
| 什么都沾一点 | 温墨 (ink) 保底 | 中性风格不会出错 |
